### Notes on design
- **Task 1 (`AsyncTaskQueue`):** a bounded semaphore-style queue enforcing
  `maxConcurrentTasks`, key-based debouncing (re-enqueue of a not-yet-started
  key cancels the prior task via `TaskCancelledException`), `cancelTask`/
  `cancelAll`, and exponential-backoff retries. Pure `dart:async` only.
- **Task 2:** fixed the refresh-token race with a **single-flight**
  `inProgressRefresh` cache so concurrent 401s share one `refreshToken()`
  call (`refreshCallCount == 1`). `ApiClient` / `AuthRepository` were created
  from the provided starters and left unmodified.
- **Task 3:** removed all hardcoded secrets/tokens, routed token storage through
  an abstract `SecureStorageContract`, cancelled the live-feed subscription in
  `dispose` (memory-leak fix), cached the parsed+sorted feed in `initState`
  (JSON parsing removed from the `build` hot path), and `mounted`-guarded all
  async `setState` callbacks.
